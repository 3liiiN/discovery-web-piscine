Discovery Web Piscine

This repository contains my work for the Discovery Web Piscine. I practiced Linux commands, file management, shell scripting, and Git/GitHub.

Why Git Makes Development Easier

Git makes development easier by keeping track of changes to my code. I can save different versions of my work with commits, check the history if I need to see what changed, and go back to an earlier version if something goes wrong.

Git also makes collaboration easier because multiple developers can work on the same project and share their changes through GitHub.
Git Workflow

The basic workflow I used was:

git add .
git commit -m "message"
git push
